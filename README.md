# 47 Skin Clinical Evidence — Speculative Email Experience

A portfolio-only React + Vite demonstration. No email was sent, and 47 Skin did not commission or approve this work.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

## Deploy to GitHub and Vercel

Create a new GitHub repository, upload the contents of this folder, then import the repository at https://vercel.com/new. Select Vite, use `npm run build`, and set the output directory to `dist`. Use a lowercase project name such as `47skin-clinical-email`.

The site loads into an illustrative Gmail-inspired inbox; only the 47 Skin campaign row opens. Use the Back arrow to return. The CTA points to https://47skin.com/pages/clinical-trials.

## Imagery

The original editorial image `public/assets/clinical-editorial-duo.png` was generated specifically for this concept, depicting two fictional models, one Black and one white, with natural skin texture. Neither is represented as a product customer, verified user, or clinical study participant. No inaccurate product packaging is depicted.
